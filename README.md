# Jogo de Adivinhação

Um jogo em Python onde o computador sorteia um número de 1 a 100 e você tenta adivinhar!

## Como funciona

- O computador escolhe um número secreto
- A cada palpite, ele diz se o número é **MAIOR** ou **MENOR**
- No final, mostra em quantas tentativas você acertou
- O jogo guarda o seu **recorde** 

## Como jogar

1. Instale o Python
2. Execute o arquivo:

```
python jogo_de_adivinhacao.py
```
